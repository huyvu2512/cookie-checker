Định dạng hỗ trợ

  • File .txt / .json chứa cookie
  • File .zip chứa nhiều file cookie
  • Chuỗi header có NetflixId
  • Định dạng Netscape cookie

Cài đặt Telegram

  1. Tạo bot qua @BotFather trên Telegram
  2. Lấy Bot Token từ BotFather
  3. Nhắn bất kỳ tin nào cho bot
  4. Lấy Chat ID tại: api.telegram.org/bot<Token>/getUpdates
  5. Bật toggle và nhập thông tin vào form

Cách dùng

  1. Dán cookie hoặc tải file ở tab Nhập Đơn
  2. Chọn chế độ: Đầy Đủ hoặc Chỉ Token
  3. Nhấn Tạo Token để xử lý
  4. Dùng tab Hàng Loạt cho nhiều file cùng lúc
